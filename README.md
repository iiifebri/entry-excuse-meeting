A single 105-character excuse for skipping a pointless work meeting: "Sorry I missed the meeting, I got stuck in traffic between my bedroom and my desk. The commute is brutal." The program writes the line to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```
